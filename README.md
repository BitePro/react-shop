# Lumina Shop

面向海外消费者的双语精品生活方式商城演示项目，使用 React、TypeScript 和 Vite 构建。

## 功能

- 英语、中文即时切换，并保存语言偏好
- 商品搜索、分类筛选和价格/评分排序
- 商品详情图片、尺寸规格选择和规格价格变化
- 按商品与尺寸区分的购物车
- 购物车数量、金额和免运费进度计算
- 浏览器本地持久化购物车
- 模拟结账反馈
- 桌面、平板和手机响应式布局

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 图片资源

演示商品和品牌图片来自 Unsplash，通过其公开图片 CDN 远程加载。项目未包含第三方商城模板或现成页面成品。
